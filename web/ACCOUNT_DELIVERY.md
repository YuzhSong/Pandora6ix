# 员工账号创建、交付及忘记密码

## 单个人员

“人员与角色 → 新增人员”填写账号和必要资料，初始密码由系统自动生成。服务端创建成功后显示“人员与账号已创建”，可显示密码、复制整套登录信息。关闭结果弹窗或重新登录后，仍可从员工卡片“账号与初始密码”查询有效交付记录。

管理员人员详情显示完整身份证号，与编辑资料保持一致。员工使用员工端登录，不能进入 Web 管理员工作台。

## 批量创建

默认使用“批量创建 → 表格填写”，可添加或删除行，填写姓名、登录账号、性别、身份证号和电话号码，初始密码自动生成；业务角色从创始人、部门老总、团队长、员工中选择，并选择匹配的组织和直属上级。空行自动忽略，点击“确认批量创建”先校验再提交，有错误时整批不创建。

同一界面提供“下载 CSV 模板”和“导入 CSV 文件”，导入后资料直接填入表格，可修改后提交；不再提供 CSV 文本输入：

1. 点击“批量创建 → 下载 CSV 模板”。
2. 用表格编辑器填写，保留全部 8 列及顺序：姓名、登录账号、性别、身份证号、电话号码、业务角色、所属组织、直属上级账号。模板和填写表不包含密码列，初始密码在后台自动生成，创建成功后通过账号交付清单查看；业务角色留空默认为员工，其他业务角色须选择匹配的组织。兼容旧模板的“职位”列名，但内容须为上述四种业务角色。账号、身份证号、电话列设为文本，避免前导 0 丢失或长数字精度变化。
3. 性别填“男/女”或 MALE/FEMALE。所属组织可填唯一名称或完整路径，如 `6ix / 产品研发部 / Web 开发组`。直属上级填写已存在且具有对应业务负责人角色的登录账号，不是姓名。业务角色对应实际权限角色并在创建时提交；系统管理员权限仍单独配置。
4. 保存为 UTF-8 CSV，导入文件并在表格中核对或修改，点击“确认批量创建”。每批 1～100 人；任一行有问题时禁止整批提交。校验账号重复、资料格式、密码长度/字节数、组织路径和直属上级。
5. 确认后逐行创建。页面显示已创建/正在创建/失败或待核实/未执行。可以停止后续创建，已发出的当前请求会完成。
6. 完成或中断后，可一键复制或下载已成功账号的 Excel 清单。某行失败时停止后续请求，不自动重试；先关闭并刷新，核实该行结果，排除已成功人员后再导入，避免重复创建。

## 批量交付

新建或重置成功的员工账号由后端加密保存交付记录，默认七天内可跨刷新、退出重登和后端重启导出。点击“批量交付”可复制或下载全部当前有效的账号与初始/重置密码；改密、过期、无记录的人员只显示状态，不加入密码清单。

员工自行改密后，服务端清除可交付密码；管理员不能查看或导出员工的新密码。忘记密码时先重置，再交付新的临时密码。复制和下载都会重新核对服务端，界面不把旧快照作为当前有效凭据。

后端须先配置外部密钥并部署 V5 迁移，详见 [交付与部署契约](../backend/CREDENTIAL_HANDOFF.md)。此前只保存 BCrypt 的历史账号不能自动恢复初始密码，也不会统一改密。

## 员工忘记密码

从员工卡片或人员详情点击“重置密码”，填写两次一致的新密码。成功后后端更新 BCrypt 密码哈希、增加人员版本、撤销该员工全部旧会话；资料、组织、角色、任务和日报保持不变。Web 显示“员工密码已重置”，提供账号和新密码的复制与交付记录。停用账号不会因重置自动启用。

只能重置本公司非 ADMIN 人员。管理员自己使用“我的账号 → 修改密码”。提交失败或结果不确定时须关闭并刷新核实，不自动重试。当前云端尚需部署 `POST /admin/users/{id}/password-reset`，未部署时页面会显示提示，不声明重置成功。

## 本轮云端数据说明

用户明确授权为现有人员补占位资料。本轮通过当前管理界面保存了 32 位人员缺失的性别、身份证号、电话，没有改姓名、登录名、密码、职位、组织或角色；新增值不是核实的真实身份资料，页面按用户要求不附测试标签。

用户随后要求现有员工登录名改成姓名拼音、密码统一，并选择由组长执行数据库调整。对应 31 位员工的映射和维护脚本见 [运维说明](../backend/scripts/EMPLOYEE_ACCOUNT_MAINTENANCE.md)。本轮尚未执行云端账号改名或统一改密，页面仍显示服务端实际登录账号；维护成功后刷新即可看到拼音账号。
