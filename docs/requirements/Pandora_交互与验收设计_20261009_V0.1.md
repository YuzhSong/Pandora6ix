# Pandora 交互与验收设计 V0.1

2026-10-09；依据[第二章V1.3](Pandora_第二章_20261009确认修订版_V1.3.md)。
本文件为后续实施验收设计；以下均为Planned，未运行、未截图验证。UI排版不改变业务范围。

## 1. 页面职责

底部五页：导图｜视图｜日志｜AI地图｜我的。任务创建/执行在视图；日志页仅日报。导图信封保留未来消息/审核，日志删除信封。权限由Backend判定，客户端隐藏只是辅助。

## 2. 导图

| 交互编号 | 行为 | 验收设计 |
|---|---|---|
| I-DASH-01 | 四面板摘要保持一行，超出省略 | 长内容不跨行；单条详情显示完整内容；数据不被截断存储 |
| I-DASH-02 | 展开保留可见底层的统一弹层，列表滚动 | 相同字号体系、返回恢复四面板；展开不是数据编辑 |
| I-DASH-03 | 单条点击打开其详情 | 公司事项→事项详情；派发→任务详情；个人两面板→工作条目详情；不跳整组 |
| I-DASH-04 | 个人重要事项编辑 | 显示最近十自然日已发布日报条目；选/取消≤10；保存刷新导图；取消不保存 |

标题固定、内容可内部滚动；四面板等高和简洁边界保留LoFi设计方向。编辑候选含日期/记录时间/完整工作内容而非AI摘要。候选≤10且未手动设置才默认全选；手动保存空集合仍为空。>10不可自动默认前十。跨账号不可读取/修改他人选择。已选条目失效后的保留/剔除/补位先按Q-06确认，不自动添加。

## 3. 任务视图

- I-VIEW-01：模式入口手动选日/周/月；选日期或空白不改模式，点击任务一律直接详情。
- I-VIEW-02：日期栏相邻切换以及直接年月日定位。可跳到多年以前，不能被导图十天窗口限制；回到今天不改变模式。
- I-VIEW-03：三个视图不出现日报/工作条目。日/周同样分全天与定时；无小时的任务在全天区域。
- I-VIEW-04：月历七列、完整首尾周；四/五/六周按实际月份。连续任务同周连续色条、跨周分段仍同ID；溢出显示数量并在当前模式展开该区间列表，不强制下钻。
- I-VIEW-05：主标签决定任务颜色；无标签中性；多个标签筛选AND，空筛选显示全部有权任务。
- I-VIEW-06：固定加号统一入口，普通员工仅个人任务；未批准只申请态，不能假装派发成功。

周/日紧凑行间距和月历容量随屏幕适配，不固化最多五周/两条/六条为数据规则。无标签、主次混用、跨月/跨年和同日多任务需一致查看。模式变化不重建任务数据。

## 4. 创建与任务详情

- I-TASK-01：类型（权限决定）、名称、备注、重要程度、全天/定时、起止日期/分钟、可选标签。主标签明确显示，不把任意遍历顺序当颜色依据。
- I-TASK-02：派发接收人以@触发候选检索，在专用候选层滚动/勾选；支持一个或多名直属及跨级下级。搜索/勾选不造成表单整页误滚，服务端再次校验范围。个人任务本人锁定，不显示可派他人的候选。
- I-TASK-03：详情读完整任务要求及时间/备注/标签，删除独立“当前状态”展示块；合法进度、完成/申请操作按后台状态与权限决定，隐藏块不删除状态。
- I-TASK-04：个人批准后本人标记完成；其他人拒绝。派发接收人完成申请、发起人逐人验收；其他接收人进度不受影响。
- I-TASK-05：创建确认文案为“提交审批”而非“立即派发”；无上级、驳回重提、批准后编辑按未决规则，不擅自默认免审。

分钟输入不得静默舍入至整点，不填具体时刻保持全天。跨日/同刻等Q-04确定前不制造验收假设。审核意见与入口均为后续，不添加当前页面或自动审批。

## 5. 日报

- I-LOG-01：今日区显示零或一篇已发布日报；无篇可新建，有篇点击补充编辑原篇。每篇多个完整工作条目，稳定身份。
- I-LOG-02：今日内容后放记录/补充入口；新内容成为该篇条目。历史按近→远，可日期筛选，列表首屏5篇、再展开后5篇；历史查询仍分页，不把10篇当永久数据上限。
- I-LOG-03：不含任务管理或信封；与任务共用标签但不染色；不要求任务关联。
- I-LOG-04：草稿/发布两个动作；发布再次确认；关闭有未保存变动先确认，确认放弃清本次未保存修改，保留此前保存草稿/已发布版本。
- I-LOG-05：本人可编辑，管理者仅有权查看。冲突提示重新加载，不覆盖另设备版本。

日志标签默认整篇日报设计；需要逐条独立标签先确认Q-09。草稿长期同步Q-03未决，不因原型内存实现宣称永久保存。新建同日第二篇收到冲突并定位本人已有篇，不丢第一次内容。

## 6. 我的、标签维护与消息

我的：本人姓名/部门/职位只读，改密、退出、字体/显示、主题。字体放大检查表单、导航、安全区域；设置不修改权限。退出后保护页不可再访问，重新登录可见已发布业务数据。

标签：部门负责人/创始人创建；Web管理员维护本企业名/色；团队长/员工只能选用。成员角色不授予跨企业权限。主次是同对象内角色，非目录父子层级。停用及历史策略Q-09。

消息：未来导图面板读消息/标已读/进入审批，保留reviewId映射和权限重校验。本轮不做页面、服务、外部邮件投递或自动处理。AI地图仍占位，无新增AI分析。
