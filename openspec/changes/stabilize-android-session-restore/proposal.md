## Why

用户报告启动时加载页与登录页自动跳变。实机抓到登录页面时，本地会话仍存在；当前启动代码将恢复会话的所有异常和取消都折叠成未登录，无法区分网络故障与真正的会话失效。设备同时存在 Android Studio 热更新覆盖层，需要完整安装复测。

## What Changes

- 启动明确区分正在恢复、已登录、未登录和可重试失败，网络错误不显示登录表单或清除会话。
- 取消传播、不发布过期恢复结果；延迟到主线程的失效回调不能清除已替换的新登录。
- 会话资料写回按原 token 校验，避免失效响应重绑账号。
- 加入启动恢复回归测试，构建完整 APK 后保留应用数据覆盖安装并进行设备检查。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `android-session-interaction`: 明确启动恢复失败与会话过期的边界和并发保护。

## Impact

仅 Android 会话恢复、登录页面切换与测试；无后端、账号、凭据或业务 API 变更。
