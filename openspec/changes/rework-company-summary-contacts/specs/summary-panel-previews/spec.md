## REMOVED Requirements

### Requirement: Three distinct overview panels
**Reason**: The task summary now contains only the task table; people and journals moved to contacts.
**Migration**: Direct reports, organization and journals are reached through the 通讯录 button on the company page.

### Requirement: Task filtering stays inside the first panel
**Reason**: The summary no longer has a three-task preview; the tabs filter the full task table directly.
**Migration**: The mine / created / managed tabs remain above the task table.

### Requirement: Task-only full list
**Reason**: The table itself is the complete paginated task list.
**Migration**: Use the table's load-more footer instead of “查看全部任务”.

### Requirement: Bounded people and journal previews
**Reason**: People and journal previews were removed from the summary.
**Migration**: Contacts shows the complete direct-report list and journal lists with date filters.

### Requirement: Compact task presentation
**Reason**: Task cards in the summary were replaced by table rows.
**Migration**: Table rows show the same real fields as columns; member detail keeps compact task cards.
