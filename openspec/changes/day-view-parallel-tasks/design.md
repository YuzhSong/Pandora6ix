## Context

TimeGrid 共用 staggerTimedTasks，按深度缩进但卡片宽度仍覆盖右侧区域。

## Goals / Non-Goals

目标：日视图重叠任务并排、时间线位置不变、列可复用且确定性排序。非目标：周/月/年视图调整或任务 API 变更。

## Decisions

增加日视图布局函数：按开始时间、结束时间倒序、ID 稳定排序；以相交区间连通组分组，结束恰等于下个开始不算重叠。分配最左侧空闲列，组内列数取最大同时占用列数。每组卡片等宽，横坐标为列号乘列宽；纵坐标和高度保留原分钟换算。全天与跨天任务复用当天裁剪区间。日视图卡片直接选中对应任务，周视图继续原叠放及时间候选选择。

## Risks / Trade-offs

大量同时任务导致卡片变窄 → 保持现有标题截断，完整内容通过点击查看。链式重叠组中部分空白 → 保持组内固定列宽避免卡片中途变宽和错位。
