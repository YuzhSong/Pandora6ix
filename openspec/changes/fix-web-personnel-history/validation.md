# 修复与验收

## 最终行为
- 普通员工选择直属上级后同步所属组织；随后仍可手动选择组织。新增、编辑、岗位调整及批量入口保持一致。
- 人员历史展示完整前后对照；优先历史名称，缺失时显示当前目录参考或原始标识，不改写历史事实。负责人候选显示组织路径。
- 岗位调整和离职由生命周期入口写一次语义日志，不再额外生成相同的账号修改日志。
- 新建人员根据姓名生成小写拼音账号，重名追加数字；批量空账号自动补全。新生成密码为12位随机纯数字。已有账号密码不变。
- 发放、复制及Excel包含企业域、登录名和原始密码；数字密码以文本保存。移除用户指定的解释性文案。
- ExcelJS显式纳入Vite预构建。旧模块请求曾返回504 Outdated Optimize Dep，强制重建缓存后模块请求HTTP200。
