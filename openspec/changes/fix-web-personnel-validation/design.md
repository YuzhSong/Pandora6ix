# Design

## Context

人员写入已经使用企业行锁。Web 批量表格与 CSV 共用预检，人员页面从服务端角色集合生成标签。

## Goals

在现有人员管理流程中提供明确的输入反馈，并在服务端阻止并发写入重复证件号。

## Decisions

- 在原有企业行锁内查询证件号。创建和变更号码执行查重，通过原样保留号码兼容历史数据。
- 在 Web 人员写入和批量预检中复用姓名校验，接受纯汉字或纯英文字母。
- 电话按数字串查重，保留原录入格式。历史重复号码保持原值时可继续编辑其他资料。
- 使用岗位展示规则隐藏负责人的员工标签。角色配置继续使用服务端返回的角色集合。

## Risks and deployment

历史重复资料由管理员核实后逐项更正。部署 Web 与后端后，可同时验证预检提示和接口并发保护。
