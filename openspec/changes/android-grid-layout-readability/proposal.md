## Why

The latest Home layout has the desired static four-panel composition, but its shared cream surface no longer matches the navigation tone and the compact text hides the full ten-item collections. The prototype also needs a final spacing pass so cards and view grids read comfortably on a phone.

## What Changes

- Restore Home's pale warm-yellow background to match the bottom navigation.
- Keep each panel title fixed while making only its item region vertically scrollable.
- Increase item typography and row spacing, adding dashed separators between records.
- Tune Home and View padding, grid spacing, and card proportions for less crowded screens.

## Capabilities

### New Capabilities
- `grid-layout-readability`: Readable scrollable panel contents and consistent prototype spacing.

### Modified Capabilities

## Impact

- Android Home/View Compose layout only; no new dependencies, data, or module changes.
