## Context

LoFi 使用 Compose、模拟数据及五页导航。此前日志页包含任务管理；视图选择由 clickable Card 承载。

## Goals / Non-Goals

Goals：落实六项核对意见，确保面板等高及独立滚动、菜单可触达、日志职责单一、个人资料可见。
Non-Goals：不设计新的任务派发审核入口，不连接后台，不改变四面板业务内容。

## Decisions

- 保留现有权重布局，移除总览标题行，将空间交还四面板。条目 4dp 垂直 padding 改为 1.33dp，分隔线用绘制而非有字体高度的文本。
- 视图切换使用标准 OutlinedButton 与 DropdownMenu，设置明确可点击标签；内容使用剩余高度容器。
- 移除日志页任务管理切换及任务派发审核 UI，保留日志可选关联任务字段，它不构成任务管理。
- 我的页采用资料卡、信息行及演示说明，不添加无响应的账户操作。

## Risks / Trade-offs

- 原型数据和日期仍为既有演示数据 → 页面明确标记模拟资料。
- 任务管理交互尚未设计 → 本轮仅保留视图现有任务查看和详情，不新增假入口。
