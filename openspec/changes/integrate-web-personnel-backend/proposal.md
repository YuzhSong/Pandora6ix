# Proposal

## Why

最新 dev `fff4e6e` 已合入后端人员资料和组织类型支持，Web 需从待接入状态转为实际可保存，并兼容个人资料尚未补齐的历史员工。

## What Changes

- 保持单公司范围、无自助注册及无标签/任务/日报业务入口。
- 对接真实人员创建/编辑和组织类型变更，保留旧后端字段缺失保护。
- 新建人员三项资料必填；编辑历史人员允许逐项补充，修改姓名或角色不要求补齐全部资料，不允许假装清空后端会保留的既有值。
- 在隔离后端副本验证创建账号、登录、刷新持久化、角色/部分资料修改和组织双向变更。
- 更新 Web 接入说明。系统日志和头像接口仍未实现，日志存储待甲方确认，不擅自选择。
- 明确展示、复制人员登录账号及公司登录标识；创建成功后提供仅当次可见的初始密码交付信息，不保存或回读密码。
- 批量 CSV 创建员工，逐行结果、停止后续创建与部分成功保护；交付清单批量复制/下载。在本页保留新建/重置密码的交付记录。
- 人员详情显示管理员已可编辑的完整身份证号；增加员工密码重置对接（后端实现见 normalize-employee-login-credentials）。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `organization-directory`: 真实人员资料接入与历史资料逐项维护。

## Impact

仅修改 Web 代码、测试、说明和本次 OpenSpec 记录。不修改 backend/ 或 android/；来自 dev 的后端更新只作为集成基线。无云端测试数据写入，不自动提交、推送、合并或部署。
