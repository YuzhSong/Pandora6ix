# Proposal

## Why

同一组织同时设置多位负责人会使人员管理和交接产生歧义。

## What Changes

- 每家公司最多一位创始人，每个部门最多一位部门老总，每个团队最多一位团队长。
- 新增、批量创建和岗位调整遇到占用时提示管理员通过负责人交接处理。
- 部门老总空缺时，新建人员默认该岗位。岗位调整只允许一个业务岗位。
- 普通员工归属具体团队，部门只直属部门老总。交接和撤销离职时处理原岗位对应的团队。
- Web 根据目标所属组织和岗位自动设置直属上级，负责人离职通过交接更新下属关系。
- 已离职人员支持撤销离职并追加变动记录。
- 系统日志显示当前页及总页数。
- 保留历史记录，允许管理员按人员实际情况逐步纠正既有重复岗位。

### New Capabilities

### Modified Capabilities

- `organization-directory` 增加人员管理中的岗位占用提示。
- `backend-identity-directory` 强制执行负责人岗位唯一性。
- `personnel-lifecycle` 支持撤销误操作的离职。
- `web-operation-history` 显示分页总数。

## Impact

涉及 Web 人员管理及现有后端人员创建、编辑和负责人交接接口。
