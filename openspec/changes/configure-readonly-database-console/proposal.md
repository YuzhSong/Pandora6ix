## Why

用户明确要求配置浏览器查看当前云端数据库。H2 文件库由后端独占打开，外部进程直接打开会发生文件锁冲突；需要实时只读入口及可重复的访问脚本。

## What Changes

- 提供可选的运维启动器，在原后端同一 JVM 启动仅监听 127.0.0.1:18082 的 H2 Console，复用实际数据库连接模式；不更换数据库、不修改应用发布成品或业务 API。
- 创建 PANDORA_VIEWER 非管理员账号及 PANDORA_VIEW 只读业务视图，隐藏密码哈希、会话和初始化凭据等内部数据，拒绝业务写入和 DDL。
- 为当前空密码的数据库管理员设置随机外部密码并更新服务器私密环境文件；口令、SSH 私钥和访问说明仅保存在服务器私密配置与操作者本机，不进入 Git。
- 配置仅允许转发到该端口的独立 SSH 密钥账号，并提供本机隧道启动/停止脚本和网页入口。先一致备份再短暂重启，检查业务和浏览器登录、只读约束、实时读取及重启行为。

## Capabilities

### New Capabilities

- `readonly-database-console`: 经 SSH 隧道访问真实 H2 的只读网页运维查看。

### Modified Capabilities

无；现有公共 Web/API 与 dev 发布/停服备份契约保持兼容。

## Impact

deploy/db-console 运维源码、systemd drop-in、专用 SSH 账号、公钥与私密外部配置。控制台与应用同进程退出，既有发布器停服后仍能复制关闭的文件数据库。用户已明确授权配置云端入口；本轮在独立 codex 分支保留可审查实现并提交 PR，不自行合并普通 PR。其他项目服务不在范围内。
