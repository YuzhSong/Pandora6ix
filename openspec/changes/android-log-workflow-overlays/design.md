## Decisions

- Keep the existing Work Logs / Task Management segmented switch.
- Work Logs shows today's entries first, then history filtered by a selected demo date; history defaults to five newest and expands to ten.
- Task Management defaults to five newest tasks and expands to all mock tasks.
- Ordinary employee dispatch/review actions are visibly disabled and explain the permission boundary when tapped.
- Use a scrim plus centered cream card for compact create/permission overlays, and a right-aligned 50% width cream drawer for notifications.
- Reuse existing mock logs/tasks and add no database or network behavior.
