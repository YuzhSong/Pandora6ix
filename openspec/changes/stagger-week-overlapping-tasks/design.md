## Context

TimeGrid 的周/日视图共享渲染，定时卡片当前以开始时间排序并整列覆盖。

## Goals / Non-Goals

Goals: 周视图以小幅错位保留被覆盖任务的左边缘，时间跨度与点击详情不变。
Non-Goals: 不调整月/年视图、接口或任务数据。

## Decisions

整点线在 TimeGrid 的 drawWithContent 中于任务内容之后、当前时间指示线之前绘制，00:00—24:00 每小时一条，使用 Ink 10% 透明度、1dp 实线。删除原背景层整点虚线，保留日期列分隔虚线；整点线只绘制到 24:00，不延伸到底部按钮避让留白，不参与触摸命中。

日/周任务卡片左侧绘制 3dp 同色深色竖线，受卡片圆角裁剪约束。优先使用首位主标签的原始 colorHex，缺失或无效时回退 displayColorHex。转 HSV 保留色相，彩色饱和度增加 0.20（上限 1），明度乘 0.70，输出完全不透明；中性色（饱和度不超过 0.02）不增加饱和度。浅绿生成深绿、浅蓝生成深蓝，原色已不透明时同样加深。无有效颜色时使用 Ink 55% 中性灰。标题左内边距为 7dp，点击区域、卡片宽高与时间位置不变。

周/日视图都移除横条区，全部任务进入时间轴。使用独立的 timelineTimeRangeOnDate：全天任务在覆盖日期返回 0 until 1440，其他任务沿用 timeRangeOnDate。全部参与错位叠放，跨多日按覆盖日期逐列显示，点击仍打开原任务。不修改 isAllDay、timeRangeOnDate 或任务数据。日视图保留原小时高度、标题字号与定时任务时间说明。

按当天裁剪后的开始时间、结束时间降序、任务 ID 稳定排序，同刻长任务在底层。每个任务的层级为仍在进行的前序任务最大层级加一；无活动任务时重置为零。使用严格的区间交集，端点相接不重叠。

每层优先缩进 6dp；按当天最大层级限制总缩进不超过列宽 35%。卡片右边缘保持在当天列边界，纵向起止不变。继续按排序顺序绘制，使前序任务的左侧区域保留可点击入口。相比并排分栏，叠放更符合截图要求。

周视图卡片在任务色下先绘制不透明 WarmCard 衬底，保证无标签的半透明灰色及带透明度的标签色不会透出底层标题；保留原任务色混合效果及圆角裁剪。

## Risks / Trade-offs

点击卡片时按局部纵坐标换算当天分钟，使用当天裁剪后的半开时间区间筛选任务，不沿全天任务扩展为整天关联组。单个候选直接打开，多个候选弹出可滚动底部列表。列表展示完整标题、任务颜色与原始日期时间，行高至少 56dp；选择后先关闭再打开详情，返回或下滑只关闭列表。无障碍点击卡片按其开始时刻进行同样选择。候选从当前任务数据推导，避免列表保存过期任务快照。

极多层重叠时露出的条带会变窄 → 限制总缩进保护标题宽度；不承诺完全重叠时所有标题同时可读。
