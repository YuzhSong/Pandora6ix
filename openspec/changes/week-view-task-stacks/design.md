## Context

周/日共用 TimeGrid，周视图需要从小时坐标改为每日任务列表。

## Goals / Non-Goals

目标：七列紧凑卡片、明确排序、独立点击、可纵向浏览。非目标：复制图片顶部导航、改日/月/年视图或任务接口。

## Decisions

新增 WeekTaskStacks，日期栏周视图去除 40dp 小时轴留白，七列与卡片对齐；卡片等高 88dp，标题最多三行，时间放底部，间距 4dp，长列通过统一纵向滚动访问。保留标签底色与深色边线。排序使用原始开始日期/分钟（全天为 0），总持续时长按跨日分钟数计算（全天包含末日），同值以 ID 排序。跨天任务在每个覆盖日重复展示，标记“续”及原始开始时分。不使用当天裁剪后的时长作为排序键。

## Risks / Trade-offs

七列文字空间有限 → 多行标题并截断，点击查看详情。海量任务 → 先保留现有简单列表范围，避免引入新依赖。
