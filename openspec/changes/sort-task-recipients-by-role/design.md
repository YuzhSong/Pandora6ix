## Context

任务候选按姓名与 ID 分页。Android 根据组织 ID 还原部门和小组，职位名称用于展示。

## Goals / Non-Goals

**Goals**

任务 @ 选人按业务角色从高到低排列同一节点下的成员。同级沿用候选顺序。

## Decisions

- 现有候选查询返回 `businessRank`，取账号拥有的最高业务角色。数值从 0 到 3 依次对应创始人、部门长、组长和员工。沿用现有候选范围与分页键。
- Android 在各节点内稳定排序。接口排除的本人继续用 `/me` 补入，等级从本人的角色计算。子组的成员仍在各自的小组内。
- 任务 @ 面板启用组内排序。通讯录继续沿用原有顺序。

## Risks / Trade-offs

旧接口缺少等级时，未分级成员保持相对顺序并排在已分级成员之后。排序使用面板已有候选，包括按现有规则补入的本人。
