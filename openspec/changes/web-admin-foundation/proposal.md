# Proposal

## Why

Web 需要承载 Android 业务依赖的企业、组织、人员与标签维护。用户已确认持续开发最终管理端，依据 V1.3 FR-USER-01～11、FR-TAG-03、FR-DASH-08 完善管理流程及账号显示设置。

## What Changes

- 创建管理员工作台入口与响应式后台，移除产品中的演示标识；底层开发数据状态只写在开发文档。
- 提供当前企业基础信息、组织结构、人员查询与新增编辑、直属上级与固定角色配置。
- 提供企业共用标签名称及颜色维护，不加入删除或停用策略。
- 将模拟数据、校验与存储封装在独立 repository，演示数据刷新后保留，退出清除演示会话。
- 提供表单反馈、未保存退出保护及键盘可访问交互。
- 增加公司重要事项新增、编辑、完整详情与顺序维护。
- 增加本人资料、主题与字号偏好，按账号本机持久化。
- 增加可配置的 HTTP transport，兼容 API 草案与现有后端错误格式；不猜测业务 DTO 或混用服务端身份和本地企业数据。
- 正式认证、业务 API、企业创建 API、私人日志汇总和审批仍待后端契约，不把进入工作台当服务端认证。

## Capabilities

### New Capabilities

- `web-admin-shell`: 管理员演示会话、导航、响应式布局与反馈。
- `organization-directory`: 当前企业、组织、人员、直属上级与固定角色维护。
- `enterprise-tag-management`: 管理端企业共享标签名称与颜色维护。
- `web-account-preferences`: Web 本人资料与本机主题、字号设置。
- `company-important-maintenance`: 公司重要事项创建、详情、编辑及顺序维护。

### Modified Capabilities

无。现有 app-settings 明确属于 Android 低保真原型，不改变其规格。

## Impact

仅修改 web/ 与本次 OpenSpec。沿用 React、TypeScript、Vite，不增加基础设施、业务接口、数据库或新的运行依赖。后续需与后端统一认证、企业管理接口及错误响应格式后另行接入。

## Latest visual revision

用户要求参考 Apple 官方 UI 并将导航移动到页面顶部；统一调整工作台、表单、入口与浅色/深色主题，保留业务行为和已有数据。此修订取代之前的暖黄色侧栏设计。

用户随后明确保留 App 端配色：采用暖黄色和米白，Apple 参考用于布局、层次和顶部导航。

## Form and responsibility correction

根据用户截图修复必填标记换行，移除说明式文案与无意义组织图例，采用独立放弃确认弹窗；人员表单只维护资料和组织关系，角色页面独立维护角色。组织创建按公司/部门上下文预填有效上级，已有公司根节点不显示上级选择。企业创建应为独立企业初始化流程，当前单企业组织新增不伪装为企业创建。

## Compact management and enterprise creation

本轮用户要求合并人员/角色，按组织或固定业务角色分组显示人员，账号与设置分别从角落进入，明确企业创建入口，并核对四面板及 MVP。实现本机企业工作空间创建和切换，原企业资料完整保留，各企业的组织/人员/标签/事项隔离；此功能不冒充服务端企业创建、认证或跨端同步。

## Company-scoped administrator correction

用户确认按需求限制本企业管理员：撤销日常多企业创建/切换扩展，保留首次公司初始化及本公司资料维护。现有 catalog 仅用于兼容保留，不再公开企业列表或切换操作。
