## Context

消息点击时主动将 notifications 清空；进入详情后 HomeScreen 离开组合，其局部保存状态没有外层保存容器承接。

## Goals / Non-Goals

**Goals:** 从消息进入详情或审批后返回仍显示消息列表，支持连续阅读；明确关闭列表仍回首页。

**Non-Goals:** 更改已读接口、消息目标解析或新增导航框架。

## Decisions

- 复用按用户隔离的 SaveableStateHolder 为首页保存 UI 状态，详情离开后能恢复。
- 消息打开目标时保留抽屉打开状态，仅清除单条通知展开定位；返回不自动重复打开目标。
- 系统返回在抽屉可见时关闭抽屉，详情页现有返回处理保持不变。

## Risks / Trade-offs

跨账号恢复旧状态 → 保存容器沿用 currentUser.id 隔离。底栏导航保存首页状态 → 用户可通过关闭按钮、遮罩或系统返回显式退出消息列表。
