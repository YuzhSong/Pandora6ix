## Context

- 主题由 `AppTheme(key, label, colors)` 描述，`PandoraTheme(theme)` 同时提供 `LocalAppTheme`、语义 Token 与 Material3；主题按账号保存在 `ThemePreferences`，未知 key 回退第一套。
- 底部导航是 `MainActivity` 中的 Material3 `NavigationBar`，图标为矢量 `ImageVector`；一级页面除导图页外根部透明，外层 `Surface` 绘制 `appBackground`。
- 素材为 8 张 1179×2556 手机截图（`素材/`）：4 张主题预览、主题选择页、首页四象限、视图页、逾期列表。

## Goals / Non-Goals

**Goals:** 四套卡通主题与原五套并存；手绘导航图标、“+”按钮、场景插画、卡片深色描边；不影响原五套与业务逻辑。

**Non-Goals:** 不改页面结构、导航名称与业务流程；不做逾期页兔子平铺底纹、四象限空状态插画、页面切换动画（后续可加）；不删除原五套主题。

## Decisions

### 1. `ThemeArt` 挂在 `AppTheme` 上
`AppTheme(key, label, colors, art: ThemeArt? = null)`。`ThemeArt` 持有场景插画、5 个导航图标、“+”按钮、可选视图页插画的 drawable id，以及导航条地面色 `navBand`。`art == null` 即原五套，所有卡通分支都以此判断，原主题渲染路径不变。
- 备选：新增独立的“皮肤”设置项——会出现“卡通皮肤 + 暖米配色”等未设计的组合，放弃。

### 2. 配色取自素材并过对比度测试
| 主题 | appBackground | primary（按钮/链接） | primaryContainer | navBand |
|---|---|---|---|---|
| 奶油单车 | #FFFEF2 | #B04A3A | #FFE4DC | #FFEFB4 |
| 凉风习习 | #F1FBFF | #2D6A88 | #D9EFFA | #E6F1AD |
| 农场乐园 | #FFF6C5 | #96541C | #FFE7B0 | #FEDE84 |
| 春日郊游 | #EAF6C2 | #44702A | #DDEDB4 | #D4EA94 |
素材里的珊瑚红、粉色等原色白字对比度不足（如 #FC8470 仅 2.6:1），只出现在插画和“+”按钮位图中，不作为按钮 Token。卡片描边色 `cardBorder` 统一为 #3A322E。

### 3. 素材裁切流程（可复现）
脚本按截图坐标裁切：场景取主题选择页大卡片（分辨率最高、无按钮遮挡），农场取预览并截到“+”左侧；顶部 28% 做透明渐变以融入背景。图标从首页（默认主题，大图）与预览（其余三套）裁切，用从边缘泛洪的方式去掉浅色背景（深色描边阻断泛洪），再去除小于最大连通块 3% 的碎片；“+”按钮用圆形遮罩。输出 WebP 到 `res/drawable-nodpi`，共 29 个约 240 KB。

### 4. 场景插画放置
一级页面在外层容器最底层绘制场景（`fillMaxWidth`，底部对齐导航条上沿），页面内容在其上；导航条在卡通主题下使用 `navBand` 背景。导图页根部背景改为透明（外层已绘制同色背景，对原主题无视觉变化）。视图页以 35% 透明度绘制（奶油单车改用素材自带的淡彩视图插画），日历内容在上层。二级页面、弹窗不显示场景。

### 5. 导航与“+”按钮
卡通主题下 `NavigationBarItem` 的 icon 换成 28dp 位图，不着色；选中态由主色文字与浅色指示器表达，未选中图标保持不透明，以免手绘图标显得“禁用”。“我的”的审批角标逻辑不变。日历 FAB 在卡通主题下替换为 64dp 位图按钮，保留 48dp 以上触区与“添加任务”读屏文字。

## Risks / Trade-offs

- [截图分辨率有限，预览里的图标原始约 70px] → 导航图标显示 28dp（420dpi 下约 74px），基本不放大；场景插画宽约 1000px，在 411dp 屏上清晰。
- [插画在长列表页底部可能被内容遮挡] → 场景在内容下层，属预期；列表滚到底时露出。
- [素材版权] → 仅限课程演示，README 与本变更注明来源；仓库公开属用户决定，已告知风险。

## Migration Plan

纯客户端新增；原主题 key 不变，已保存的偏好不受影响。回滚即删除四个 `AppTheme` 条目与资源，选了卡通主题的账号会回退到暖米。
