## Context

Android 已有 pending/created 审批分页查询。入口只加载 pending，普通提交人没有角标。结果只需应用内数字提示。

## Goals / Non-Goals

Goals: 通过和拒绝结果均可发现，查看详情后逐条清除，账号隔离，重启保留。
Non-Goals: 跨设备已读同步、系统推送、后端表与接口扩展。

## Decisions

- 复用 created 查询，遍历所有分页，以审批 id、decision、decidedAt 构成结果标识；仅 APPROVED/REJECTED 算未读。
- SharedPreferences 按用户 ID 隔离保存已读标识。首次安装已有的决定也作为未读，避免漏掉拒绝记录。列表展示“新结果”，点击该条详情时标记已读；打开中心不批量清除。
- 总角标为待我审批数加未读结果数，沿用 99+；无审批权限仍查询本人结果。前台 STARTED 时每 30 秒刷新，切页、返回中心立即刷新。单项查询失败保留上次成功值；取消协程不吞异常。
- 列表使用同一未读集合，并在前台刷新后重新加载当前队列；正在详情时不自动替换详情。

## Risks / Trade-offs

- 本机已读不跨设备同步 → 明确限定本地提示，复用接口以控制范围。
- 历史记录多时分页开销增加 → 每页 100 条，前台限定刷新，未读达到 99 条即可停止计数扫描。
